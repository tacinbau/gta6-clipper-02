A vertical GTA 6 clip cut from a live Twitch stream, with a make.fun pitch baked in, posted as a public YouTube Short. This is the channel's most-viewed Short: caseoh_'s Dealer's Choice run — "PICK YOUR PRODUCT!" — Fly Boy and the Blocks, packed into under a minute of vertical video with the original stream audio. Mid-clip it tells viewers they can make money making clips with AI, and it closes on a full-screen make.fun end card.

Bounty: [Clip GTA 6 for the most YouTube views](https://make.fun/bounty/gta6-clipper-01)

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) copies `VIDEO.json` from the bot directory into the output directory. It reads `MAKEFUN_BOT_DIR` (default `/bot`) and `MAKEFUN_OUTPUT_DIR` (default `/output`). `VIDEO.json` holds the URL of the published Short: https://www.youtube.com/shorts/5pb3_j0fb44
